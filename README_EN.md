### Description
**Markhive** — A browser bookmark manager designed to bring order to your collection of saved websites. The program supports importing standard export files in Netscape HTML format from Chrome, Firefox, Edge, Opera, and other browsers. It operates independently, requiring no link to a specific user profile or installed browser. The manager allows you to perform basic operations on bookmarks and folders—such as creating, moving, renaming, and deleting items—to establish a clear and organized storage structure.
